## Structure
```
code/               original programs (Task_02 … Task_20)
code/extensions/    modified programs (parameter change + related case)
outputs/            console output of every program
outputs/figures/    graphs saved by the programs
docs/               documentation per task
run_all.sh          runs everything and regenerates outputs
```

## Run
```bash
pip install -r requirements.txt
bash run_all.sh
```
